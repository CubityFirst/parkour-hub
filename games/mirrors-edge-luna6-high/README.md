# SKYLINE — Rooftop Flow

A small first-person rooftop parkour game built with Three.js, TypeScript, and Vite. The route is an original six-section city sprint with checkpoints, local best-time tracking, sprinting, jumping, sliding, vaulting, wall-running, and a zipline crossing.

## Run locally

```sh
npm install
npm run dev
```

Open the local URL printed by Vite in a desktop browser. Click **Run the Route** to capture the mouse. Press Esc to pause and unlock the mouse.

## Controls

- WASD move, mouse look
- Shift sprint
- Space jump / kick away from a wall
- Ctrl or C slide
- E vault / grab the zipline when prompted
- R return to the latest checkpoint
- Esc pause

The best completion time is saved in browser local storage.
