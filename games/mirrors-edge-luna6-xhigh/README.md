# Rooftop Flow

A browser based first person rooftop parkour game built with Three.js, TypeScript, and Vite. The course uses procedural geometry and original level design; no downloaded assets or backend are required.

## Run locally

    npm install
    npm run dev

Open the local URL printed by Vite. Use a modern desktop browser with WebGL enabled.

## Controls

- **W A S D** — move
- **Mouse** — look
- **Shift** — sprint
- **Space** — jump or kick away from a wall-run
- **Ctrl / C** — slide
- **E** — vault a red service block or mantle a nearby ledge
- **R** — return to the latest checkpoint
- **Esc** — pause / release the mouse

The level has five checkpoint markers before the finish gate. Your best completion time is saved in local browser storage.
