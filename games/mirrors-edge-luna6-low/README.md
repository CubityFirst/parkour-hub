# Rooftop Flow

A first-person rooftop parkour game built with Vite, TypeScript and Three.js. It uses procedural geometry and Web Audio; no downloaded game assets are required.

## Run locally

```bash
npm install
npm run dev
```

Open the local Vite URL in a desktop browser. Choose **Run the Roofs** to lock the mouse. Esc pauses and releases it.

## Controls

- WASD move, mouse look
- Shift sprint, Space jump (release early for a shorter jump)
- Ctrl slide under the low roof units
- E vault a low obstacle
- R return to the latest checkpoint

The route's red rooftop pads and markers show the intended direction. Complete the final red gate to save your best time locally.
